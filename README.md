# Mahesh Gunalapuri & Associates — Website

Website for Mahesh Gunalapuri & Associates, Chartered Accountants, Nalgonda: a firm profile, CA portfolio, services, insights (blog) and a consultation request form.

**Stack:** React 18 + Vite 5 + TypeScript, Tailwind CSS 3, React Router 6, React Hook Form + Zod, Lucide icons, Framer Motion (mobile menu and hero only), react-helmet-async for SEO tags. Tests: Vitest + React Testing Library, Playwright. Hosting: Netlify (free plan). Contact form: Web3Forms (free plan).

Firm name, contact details, office address, services and track-record figures are real. The founder’s biography, qualifications, experience, ICAI number and photo are still **placeholder content**. Placeholders are written in `[square brackets]`, sample figures are labelled “Sample figure”, and demo articles are labelled “Demonstration content”.

---

## 1. Replace the placeholder information

Almost everything lives in **one file: `src/config/siteConfig.ts`**.

| What | Where in `siteConfig.ts` |
|---|---|
| Firm name, tagline, description, history, mission, vision | `firm` |
| CA name, designation, ICAI membership no., qualifications, biography, experience, specialisations, industries, achievements, LinkedIn | `founder` |
| Phone, WhatsApp, email, office address, map, business hours | `contact` |
| Social media links | `social` |
| “Years of experience” / “Clients served” figures | `stats` (set `isSample: false` once verified) |
| Professional values | `values` |
| Client testimonials (hidden while empty; use only with client permission) | `testimonials` |
| Page title / description used for search engines | `seo` |

How the site behaves with empty values:

- **Phone / email**: shows “To be added” and no link. Once set, they become click-to-call and click-to-email links automatically.
- **WhatsApp**: the button stays disabled until `contact.whatsapp` is set. Use digits with country code, e.g. `919876543210`.
- **Map**: shows a placeholder panel until `contact.mapEmbedUrl` is set (Google Maps → Share → *Embed a map* → copy only the `src="..."` URL).
- **Address in search results**: set `contact.addressIsReal: true` only once the address is real.
- **LinkedIn / social icons**: hidden until a URL is set.

When everything is real, set `showPreviewBanner: false` to remove the notice at the top of the site.

Other content files:

- **Services**: `src/content/services.ts`
- **Expertise areas**: `src/content/expertise.ts`
- **Approach steps**: `src/content/approach.ts`
- **Privacy Policy / Terms**: `src/pages/PrivacyPolicy.tsx`, `src/pages/Terms.tsx`. These are template text; have them reviewed.

## 2. Add an article

Open `src/content/articles.ts`, copy an existing article object, and change:

- `slug`: lowercase words joined by hyphens; becomes the URL `/insights/<slug>`
- `title`, `category` (one of the five categories), `date` (`YYYY-MM-DD`), `readMinutes`, `excerpt`
- `isDemo: false`
- `body`: a list of blocks: `{ type: 'p', text }`, `{ type: 'h2', text }`, `{ type: 'ul', items: [...] }`, `{ type: 'note', text }`

Newest articles show first. The sitemap updates automatically at the next deployment. Delete the demo articles once real ones exist.

## 3. Change images and logo

Put image files in `public/images/`, then reference them from `siteConfig.ts`:

- **Founder photo**: `founder.photo: '/images/founder.jpg'`. Use a portrait about 800×1000 px, JPG or WebP, under 200 KB.
- **Logo**: `firm.logo: '/images/logo.svg'`. It is shown 40 px tall. Leave it empty to keep the “MGA” monogram.
- **Favicon**: replace `public/favicon.svg`.
- **Social share image** (`public/og-image.png`), `favicon.ico` and `apple-touch-icon.png` are generated by `npm run og-image`. Edit `scripts/render-og-image.mjs` to change them, or replace the files with your own (share image: 1200×630 px).

## 4. Environment variables

Copy `.env.example` to `.env.local` for local development. On Netlify, set them under **Site configuration → Environment variables**, then trigger a redeploy (Deploys → Trigger deploy).

| Variable | Purpose |
|---|---|
| `VITE_WEB3FORMS_ACCESS_KEY` | Free key from [web3forms.com](https://web3forms.com). Enquiries are emailed to the address used to create the key. Without it, the form says it is not connected yet; it never shows a false success. |
| `VITE_SITE_URL` | Live address without trailing slash, e.g. `https://mahesh-gunalapuri-associates.netlify.app` or your own domain. Used for canonical URLs, sitemap and share previews. |

The Web3Forms key is designed to be used in the browser; it only allows sending form emails to you.

## 5. Run, test, build

```bash
npm install
npm run dev          # local site at http://localhost:5173
npm run lint
npm run typecheck
npm run test         # unit + component tests (Vitest)
npx playwright install chromium   # first time only
npm run test:e2e     # end-to-end tests against a production build
npm run build        # output in dist/
```

Run the end-to-end suite against the live site:

```bash
E2E_BASE_URL=https://your-site.netlify.app npx playwright test
```

## 6. Redeploy after changes

The GitHub repository is connected to Netlify. Every push to `main` deploys automatically:

```bash
git add -A
git commit -m "Update CA details"
git push
```

Netlify builds the site in a minute or two. Check progress under **Deploys** in the Netlify dashboard.

## Free-tier notes

- **Netlify free plan**: commercial use allowed; 100 GB bandwidth and 300 build minutes per month. If limits are exceeded, the site is paused until the next month rather than billed automatically.
- **Web3Forms free**: 250 submissions/month; submissions are emailed and not stored in a dashboard.
- **Custom domain**: buying a domain costs money; connecting one in Netlify is free (HTTPS included).

## Project structure

```
src/
  config/siteConfig.ts   ← firm & CA details (edit this)
  config/routes.ts       ← page list for nav + sitemap
  content/               ← services, expertise, articles, approach
  components/common/     ← buttons, logo, SEO, icons, contact details
  components/layout/     ← header, footer, page layout
  components/sections/   ← home sections, contact form, due-dates panel
  pages/                 ← one file per page
  utils/                 ← validation, form submission, links, calendar
tests/unit/              ← Vitest + Testing Library
tests/e2e/               ← Playwright
public/                  ← favicon, share image, images/
netlify.toml             ← build settings, SPA routing + security headers
```
